# 08 - Dashboard

The Dashboard summarizes operational governance posture and helps reviewers find where attention is needed.

## Overview

Overview panels count assets by lifecycle, type, hosting model, network dependency, risk severity, and project volume. Use these counts to spot concentration in high-risk stages or connectivity patterns.

## Exposure

Exposure highlights projects and assets with open HIGH/CRITICAL risks. This is the fastest route to the most important unresolved governance work.

## Reuse

Reuse panels show assets used by multiple projects. Highly reused models, datasets, services, and libraries deserve stronger regression testing, documentation, and recertification discipline.

## Coverage

Framework coverage shows how many risks are mapped to each framework category. Empty or low-coverage categories can indicate real control gaps or simply areas that have not been assessed yet.

## Recertification And Model Cards

Recertification panels show overdue and due-soon review schedules. Model Card coverage tracks whether MODEL and SERVICE assets have complete enough documentation for governance decisions.

## Performance Metrics

The Model Performance Metrics panel compares structured Model Card metric values across models. Choose a metric name to see available values and grouped aggregate behavior.

## Search

Global search spans assets, projects, and risks so reviewers can jump directly to relevant records during audits or review meetings.
